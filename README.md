# 채널 모니터 (Channel Monitor)

등록한 유튜브 채널들이 요즘 올리는 **쇼츠를 한곳에서 보고 비교**하는 로컬 프로그램입니다.
완전 로컬로 동작하며, 인터넷에 데이터를 올리지 않습니다. (내부적으로 `yt-dlp` 사용)

- 여러 채널의 인기 쇼츠를 조회수순으로 한눈에
- 채널 목록을 여러 개 만들어 관리
- 제목·채널로 검색, 채널 비교표
- 맥 / 윈도우 모두 동작

---

## 설치 (한 번만)

### 1. 파이썬 설치
- 없으면 <https://www.python.org/downloads/> 에서 설치
- **윈도우 설치 시 "Add Python to PATH" 체크 필수**

### 2. 프로그램 준비
이 폴더에서 아래를 실행해 필요한 라이브러리를 설치합니다.

**맥 / 리눅스** (터미널):
```bash
pip3 install -r requirements.txt
```

**윈도우** (명령 프롬프트):
```bat
pip install -r requirements.txt
```

---

## 실행

### 맥
`start-mac.command` 파일을 더블클릭하세요.
(처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면 → 파일 우클릭 → 열기)

### 윈도우
`start-windows.bat` 파일을 더블클릭하세요.

실행하면 브라우저가 자동으로 열립니다. (`http://127.0.0.1:5054`)
종료하려면 터미널 창에서 `Ctrl + C`.

---

## 사용법

1. 왼쪽 `☰ 채널` 버튼 → 모니터링할 채널 핸들 추가 (예: `bbeogguk`)
2. `가져오기` 클릭 → 각 채널의 쇼츠를 조회수순으로 표시
3. `최신 트렌드 분석`(빠름) / `전체 분석`(느림) 선택
4. 상단 검색창으로 제목·채널 필터

---

## 선택 설정 (환경변수)

| 변수 | 설명 | 예시 |
|---|---|---|
| `YTDLP_COOKIES_BROWSER` | 로그인 상태로 조회하고 싶을 때 브라우저 지정 | `chrome` 또는 `chrome:Profile 2` |
| `CHANMON_PORT` | 실행 포트 변경 (기본 5054) | `5060` |
| `YT_DLP_PATH` | yt-dlp 실행 경로 직접 지정 | `/usr/local/bin/yt-dlp` |

기본값은 **쿠키 없이** 동작합니다. 공개 채널의 쇼츠 목록은 로그인 없이도 대부분 조회됩니다.

---

## 문제 해결

- **"yt-dlp를 찾을 수 없습니다"** → `pip install -r requirements.txt` 를 다시 실행
- **채널이 조회 안 됨** → 핸들이 정확한지 확인(`@` 제외). 일부 채널은 `YTDLP_COOKIES_BROWSER` 설정이 필요할 수 있음
- **포트 충돌** → 자동으로 다음 빈 포트를 찾습니다. 콘솔에 표시된 주소를 확인하세요

---

## 프라이버시

- 등록한 채널 목록(`lists.json`)은 **내 컴퓨터에만** 저장됩니다.
- 이 프로그램은 유튜브 공개 데이터만 조회하며, 계정 로그인이나 게시 기능은 없습니다.
