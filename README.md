# 채널 모니터 (Channel Monitor)

등록한 유튜브 채널들이 요즘 올리는 **쇼츠를 한곳에서 보고 비교**하는 프로그램입니다.
완전 로컬로 동작하며, 인터넷에 데이터를 올리지 않습니다.

- 여러 채널의 인기 쇼츠를 조회수순으로 한눈에
- 채널 목록을 여러 개 만들어 관리 · 제목/채널 검색 · 채널 비교표
- 맥 / 윈도우 모두 동작

---

## 설치 (파이썬 설치 불필요)

[**Releases 페이지**](../../releases/latest) 에서 자기 컴퓨터에 맞는 파일을 받으세요.

| 운영체제 | 받을 파일 |
|---|---|
| 윈도우 | `channel-monitor-windows.exe` |
| 맥 | `channel-monitor-macos` |

### 실행

**윈도우**
1. `channel-monitor-windows.exe` 더블클릭
2. "Windows의 PC 보호" 경고가 뜨면 → **추가 정보** → **실행**
   (서명이 없는 개인 프로그램이라 뜨는 경고입니다. 한 번만 넘기면 됩니다.)

**맥**
1. 받은 `channel-monitor-macos` 파일을 **우클릭 → 열기**
2. "확인되지 않은 개발자" 경고 → **열기** 클릭
   (그냥 더블클릭하면 막힐 수 있으니 반드시 우클릭 → 열기)

실행하면 잠시 후 브라우저가 자동으로 열립니다. (`http://127.0.0.1:5054`)
검은 콘솔 창은 켜둔 채로 사용하세요. 끄려면 그 창을 닫으면 됩니다.

> **첫 실행은 조금 느립니다.** 처음 한 번 유튜브 조회 도구(yt-dlp, 약 30MB)를
> 자동으로 내려받습니다. 이후에는 빠르고, 유튜브가 바뀌어도 자동으로 최신을 유지합니다.
> 첫 실행에는 인터넷 연결이 필요합니다.

## 사용법

1. 왼쪽 `☰ 채널` 버튼 → 모니터링할 채널 핸들 추가 (예: `bbeogguk`)
2. `가져오기` 클릭 → 각 채널의 쇼츠를 조회수순으로 표시
3. `최신 트렌드 분석`(빠름) / `전체 분석`(느림) 선택
4. 상단 검색창으로 제목·채널 필터

---

## 선택 설정 (환경변수)

| 변수 | 설명 | 예시 |
|---|---|---|
| `YTDLP_COOKIES_BROWSER` | 로그인 상태로 조회하고 싶을 때 브라우저 지정 | `chrome` |
| `CHANMON_PORT` | 실행 포트 변경 (기본 5054) | `5060` |

기본값은 **쿠키 없이** 동작합니다. 공개 채널의 쇼츠 목록은 로그인 없이도 대부분 조회됩니다.

## 문제 해결

- **채널이 조회 안 됨** → 핸들이 정확한지 확인(`@` 제외)
- **포트 충돌** → 자동으로 다음 빈 포트를 찾습니다. 콘솔에 표시된 주소를 확인하세요
- **백신이 막음** → 서명 없는 개인 프로그램이라 오탐일 수 있습니다. 신뢰하는 상대에게 받은 경우에만 예외 처리하세요

## 프라이버시

- 등록한 채널 목록은 **내 컴퓨터에만** 저장됩니다.
- 이 프로그램은 유튜브 공개 데이터만 조회하며, 계정 로그인이나 게시 기능은 없습니다.
